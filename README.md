## ✨ Features & Highlights

- ** Apple-Inspired Aesthetic**: Glassmorphism, smooth San Francisco typography hierarchy, dark/light mode, and subtle ambient light meshes.
- **📱 Interactive 3D iPhone Simulator**: Live interactive iOS phone mockups rendering interactive screens (SFA360, enterprise apps, metrics, and live UI interactions).
- **⚡ High-Performance Animations**: Powered by Framer Motion for 60fps micro-interactions, parallax scrolling, custom interactive cursors, and smooth section transitions.
- **💼 Comprehensive Sections**:
  - **Hero**: Highlight key metrics, direct resume download, and quick exploration.
  - **About**: Core engineering philosophies, iOS technical stack depth, and background.
  - **Experience**: Timeline of enterprise iOS roles, impact, and achievements.
  - **Featured Projects**: Deep-dive showcases into flagship iOS products with architecture breakdowns.
  - **Skills Matrix**: Technical skills across Swift, SwiftUI, Combine, CoreData, SQLite, CI/CD, and performance tuning.
  - **Achievements & Testimonials**: Impact statistics, peer recommendations, and recognitions.
  - **Interactive Contact**: Form validation with Zod and Sonner toast notifications.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher recommended)
- `npm` or `bun` / `pnpm` / `yarn`

### Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mohanraj-Freelancer/portfolio-mohanraj.git
   cd portfolio-mohanraj
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the portfolio.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
